## **RateMyRoommates - Server Infrastructure** 

Information About This Repository

This repository documents the server infrastructure my group member and I configured for CSUN's SOSE (Society of Software Engineers) Hackathon competition. 



## **Live Website:** https://ratemyroommates.dev




## **Technologies Used:**

- Windows 11 machine - hosting operating system
- Apache HTTP Server 2.4 - web server
- Cloudflare Tunnel - connection between the local server and Cloudflare
- Cloudflare DNS - domain configuration
- Node.js and npm - frontend build tools
- GitHub - documentation and version control 


## **Server Architecture**

Vistor -> Cloudflare -> Cloudflare Tunnel -> Apache -> React Frontend




## **Current Project Status**

- Windows Apache server configured
- Reat frontend deployed
- Cloudflare tunnel configured
- Custom domain connected
- HTTPS verified
- React Router fallback configured
- Firebase backend integration (in progress)
